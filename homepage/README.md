# Ardent homepage

A static homepage for Ardent, aimed at people in the trades (electricians, gas and heating engineers, plumbers, fire and security, multi-trade contractors). Plain HTML, CSS and a few lines of JavaScript, with no build step.

## Run it

```bash
cd homepage
python3 -m http.server 8000   # then open http://localhost:8000
```

## Pages

**`index.html`, the homepage**, follows the Freight services page reference:

1. Hero with full-bleed warehouse photograph
2. Our focus statement
3. Full-bleed aerial with trade labels
4. What Ardent does: four numbered services, each with a photograph
5. Trades we work with
6. Closing call to action over a night motorway photograph
7. Footer with oversized wordmark

**`engineers.html`, the engineer app page**, follows the dark developer-tool reference: certificate and sign-off log cards, hatched dividers, two feature blurbs and a teal call to action.

**`news.html`, News & Updates**, follows the News & Events reference: an orange gradient page with a grid of regulation, guide, product and event cards.

**`pricing.html`, Pricing and demo**: three plans, common questions and a demo request form. The form posts JSON to the URL in its `data-endpoint` attribute; while that is empty it opens an email to `data-email` with the details filled in.

**`product.html`, Product**: a tabbed tour of real Ardent Core screens (`images/screen-*.jpg`), then six features, each with a close-up from the app (`images/ui-*.jpg`). All were captured from the Core prototype at 1440 by 900.

**`for-<trade>.html`, one page per trade** (electricians, gas, plumbers, fire, hvac, lifts, roofers, multi), linked from the homepage trades list. They are generated: edit the copy in `scripts/build-trades.mjs` and run `node scripts/build-trades.mjs`. The menu and footer are taken from `product.html`, so rebuild after changing those.

Every page shares `styles.css`, `main.js`, the menu and the footer.

## Images (GPT Image)

Every photograph is generated by OpenAI's GPT Image model. Prompts, sizes and the shared house style live in `images/prompts.json`.

The current images were made with GPT Image 2 through Runway, using these prompts. If an image file is missing, the page shows a clearly labelled placeholder carrying the prompt that will produce it.

```bash
cd homepage
OPENAI_API_KEY=sk-... node scripts/generate-images.mjs            # every missing image
OPENAI_API_KEY=sk-... node scripts/generate-images.mjs hero cta   # selected ids only
FORCE=1 OPENAI_API_KEY=sk-... node scripts/generate-images.mjs     # regenerate everything
```

`OPENAI_IMAGE_MODEL` (default `gpt-image-1`) and `OPENAI_IMAGE_QUALITY` (default `high`) override the model and quality. Node 18 or later is required.

The same prompts also work in Runway or Higgsfield with the GPT Image 2 model: combine each `prompt` with the `style` text and save the result under the listed `file` name.
