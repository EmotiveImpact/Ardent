# Ardent homepage

A static homepage for Ardent, aimed at people in the trades (electricians, gas and heating engineers, plumbers, fire and security, multi-trade contractors). Plain HTML, CSS and a few lines of JavaScript, with no build step.

## Run it

```bash
cd homepage
python3 -m http.server 8000   # then open http://localhost:8000
```

## Sections

1. Hero with full-bleed warehouse photograph
2. Our focus statement
3. Full-bleed aerial with trade labels
4. What Ardent does: four numbered services, each with a photograph
5. Trades we work with
6. Dark engineer section with certificate and sign-off log cards, hatched dividers and a teal call to action
7. News & Updates card grid on an orange gradient
8. Closing call to action over a night motorway photograph
9. Footer with oversized wordmark

Sections 1 to 5, 8 and 9 follow the Freight services page reference; section 6 follows the dark developer-tool reference; section 7 follows the News & Events reference.

## Images (GPT Image)

Every photograph is generated by OpenAI's GPT Image model. Prompts, sizes and the shared house style live in `images/prompts.json`.

Until an image exists in `images/`, the page shows a clearly labelled placeholder carrying the prompt that will produce it.

```bash
cd homepage
OPENAI_API_KEY=sk-... node scripts/generate-images.mjs            # every missing image
OPENAI_API_KEY=sk-... node scripts/generate-images.mjs hero cta   # selected ids only
FORCE=1 OPENAI_API_KEY=sk-... node scripts/generate-images.mjs     # regenerate everything
```

`OPENAI_IMAGE_MODEL` (default `gpt-image-1`) and `OPENAI_IMAGE_QUALITY` (default `high`) override the model and quality. Node 18 or later is required.

The same prompts also work in Higgsfield with the GPT Image 2 model: combine each `prompt` with the `style` text and save the result under the listed `file` name.
