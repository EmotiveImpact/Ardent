What the latest wiring regulations amendment means for your EICRs

Every amendment to BS 7671 changes what inspectors look for. Here is how to keep your condition reports consistent while the industry catches up.

02 / 10 / 20265 min readArdent compliance team

Each amendment to BS 7671 brings new requirements for installations, and with them new questions for anyone carrying out periodic inspections. The installation you are testing was compliant when it was built. The report you write has to say whether it is safe for continued use today.

Code against safety, not against the latest edition

An installation is not automatically unsatisfactory because it predates an amendment. Observation codes should reflect real risk: C1 for danger present, C2 for potentially dangerous, C3 for improvement recommended and FI where you need to investigate further. Consistent coding is what protects you if a report is ever questioned.

What changes on site

  • Check the model forms your scheme provider expects, since they update alongside the standard.
  • Agree as a team how you will code the most common borderline findings, and write it down.
  • Photograph anything coded C2 or FI so the reasoning travels with the report.

How Ardent helps

Ardent keeps your observation library in one place, so every engineer codes the same finding the same way. C1, C2 and FI observations turn into a quote for remedial work in one tap, and every report is filed against the property with its next inspection date already booked.
