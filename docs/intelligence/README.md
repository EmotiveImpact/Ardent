## Read order

1. [Ardent Intelligence Operating Framework v0.2](Ardent-Intelligence-Operating-Framework-v0.2.md) explains the purpose, five product packages, authority boundaries, evidence and execution safeguards, first MVP, and acceptance gates.
2. [Ardent Claude Handoff Addendum v0.2](Ardent-Claude-Handoff-Addendum-v0.2.md) translates the framework into implementation guidance, baseline checks, module contracts, and required acceptance evidence for the existing codebase.

Use both alongside the full product handoff. The addendum supplements the framework and product handoff; it does not replace them. Verify current repository branches and commits before implementation.

## Product packages

- **Core:** business operations, customers, jobs, scheduling, and finance
- **Field:** the engineer's mobile and offline experience
- **Voice:** intelligent call handling, enquiries, and bookings
- **Agents:** business automation, approvals, and intelligent assistants
- **Intelligence:** revenue, profitability, and operational insights

Shared infrastructure underpins all five packages. Read the framework for their responsibilities and boundaries.
