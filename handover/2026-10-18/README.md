# ARDENT 18 October 2026 continuity handover

A **non-destructive planning and integration package** for Claude and the other agents working on the existing Ardent software. This is a documentation-only branch, not a production build or a replacement for active development.

**Start:** [00_START_HERE.md](./00_START_HERE.md), then [CLAUDE_FIRST_MESSAGE.md](./CLAUDE_FIRST_MESSAGE.md). The [master handover](./ARDENT_MASTER_HANDOFF.md) contains all fourteen chapters in one file. The individual files under [docs/](./docs/) are the same specification organised by concern.

**Important:** Ardent Core, Mobile, Homepage and the SiteSentriq import were observed on different `claude/project-thread-*` branches. Inspect actual remote branches and uncommitted development before integration. There is no authority in this pack to merge, deploy, overwrite active work or publish secrets.

**Security warning:** The Ardent repository was observed as public while it contains a snapshot of the private SiteSentriq repository. Assess provenance, publication intent and any credential exposure before further code reuse. Do not assume that deleting code from the current branch erases historical access.

This pack intentionally omits the exploratory UI image and ZIP binary: the image is not an approved design source and the canonical specifications are Markdown. The original downloadable ZIP remains in the originating ChatGPT conversation.
